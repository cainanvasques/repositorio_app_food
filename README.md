# 🥗 Fist List - Full Stack Project

Este é um projeto completo para gerenciamento de dieta, permitindo cadastrar, listar, editar e remover itens alimentares. O projeto é dividido em uma API robusta e uma interface web simples.

---

## 🚀 Estrutura do Repositório

O projeto está organizado em duas pastas principais:
* **/backend**: API REST desenvolvida com **NestJS** e **SQLite**.
* **/frontend**: -

---

## 🛠️ Tecnologias Utilizadas

### **Backend**
* **Framework:** NestJS
* **Linguagem:** TypeScript
* **Banco de Dados:** SQLite (via TypeORM)
* **Documentação:** Swagger
* **Validação:** Class-validator

### **Frontend**
* **Linguagem:** -
* **Comunicação:** -
* **Estilização:** -

---

## 💻 Como Executar o Projeto

Você precisará de dois terminais abertos para rodar as duas partes simultaneamente.

### 1. Rodando o Backend
1. Entre na pasta do backend:
    ```bash
   cd backend
    ```

2. Instale as dependências:
    ```bash
   npm install
    ```

3. Inicie o servidor::
    ```bash
   npm run start:dev
    ```

Nota: A API rodará em http://localhost:3000. 

Acesse http://localhost:3000/api para ver a documentação Swagger.
